# 🌍 BreatheSafe - GIS Air Quality Monitoring System

GIS-based Air Quality Index (AQI) monitoring system that visualizes real-time air pollution of multiple cities on an interactive map with heatmaps and alerts. A web-based Air Quality Index (AQI) dashboard that displays real-time air pollution, weather data, pollutant levels, and AQI trends using interactive charts.

## 🚀 Features
* Real-time AQI Monitoring
* GIS Map Visualization
* Heatmap Pollution Mapping
* City Search
* Weather Information
* Pollutant Monitoring
* AQI Alerts
* AQI History
* Daily AQI Reports
* India Capitals AQI Dashboard
* AQI Health Guide
* Auto Refresh AQI
* Mobile Responsive Design
* 24-hour AQI chart
* Weekly AQI chart
* Monthly AQI chart
* Minimum & Maximum AQI with date/time
* Health recommendations based on AQI
* Interactive dashboard UI

## 🛠 Technologies Used

* HTML
* CSS
* JavaScript
* Chart.js
* Leaflet.js
* IQAir API
* Open-Meteo API
* Render (Backend Hosting)
